《河灯密室》 -- 小熊饼干 出品

#网页解谜游戏 #民俗

作品简介

七月半前，表妹许禾在渡口失踪。她最后叮嘱你：别喊她的名字。


介绍：

白鹭渡有七月半放河灯的老规矩。今年暑假，许禾在奶奶家帮宗亲会把族谱录进电脑，顺手给庙里做了网上放灯登记。八月底的一个夜里，她出门以后再没回来，手机落在渡口的台阶上。
你是她在外地的亲戚程溪。游戏就是程溪的手机：家族群、相册、村里的贴吧、救援队、庙里的网站、许禾的博客等，都能点开。


游玩说明：

· 手机、电脑都能玩。没有声音，语音消息都有转文字。

· 有几处线索要在游戏外搜索。游戏里出现的外部账号都是作者为游戏建的，请不要打扰同名的真实用户。


故事纯属虚构 如有雷同 切勿当真！
