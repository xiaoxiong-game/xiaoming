《河灯秘事》攻略

每一步先给方向，再给位置，最后才是答案。三层都默认折叠，卡在哪一步就只点开那一步的下一层。

内容提示：故事涉及少年溺亡和亲属加害。

开始之前一、她不见了二、去年的平平三、水底下四、谁写的灯五、子时结局快速路线

开始之前

  • 从游戏主页点“开始游戏”，进入程溪的手机（phone.html）。别的网站都要从手机和网页里的链接一层层找到，链接会在新标签页打开。
  • 所有页面用同一个浏览器玩。进度存在这个浏览器里，各个网站共用。
  • 网址可以自己改，有一步要用到。
  • 网页里加粗的字是主线线索。通向真结局的线索大多没有加粗，要自己留意。
  • 语音消息都已经转成文字，不用开声音。方言部分转得不准，听不出的字按读音显示。
  • 有两步要用到现实里的网站：小红书（要登录）和 GitHub（不用登录）。没有小红书也能通关，第17步写了另一条路。
  • 想重来：手机桌面的“重新开始”。
一条贯穿全程的规矩（轻剧透）

许禾的小名在哪里都不要写出来。聊天框里不要打，最后视频里小姨帮你写条子，也不要让她写。写过一次，最后就喊不回她了。

一、她不见了

01先看手机

弄清楚发生了什么，找到第一个网站。

方向

聊天记录和相册都翻一遍。家族群里有人转了一个网页。

位置

微聊里的“禾禾”和“许家一家亲(8)”；桌面上的相册。

答案

8月24日禾禾发来一张晒谷场照片和一条语音，转文字是“ā mò，ā mò，转来哦”，她说是奶奶在喊她小名。夜里又说“这几天别喊我名字”“打字也别打”。家族群里有寻人启事、外婆的三条方言语音（转文字不太准，小姨翻译了前两条，第三条只听出“莫喊她大名”）、小姨转发的“白鹭渡吧”链接卡片。点卡片进吧。

02寻人帖

在吧里找到大舅发的寻人帖。

方向

人是昨晚不见的，大舅凌晨在吧里发了帖，帖子还很新。

位置

吧首页第二帖，就在置顶的吧规下面。

答案

打开《【急】寻人：白鹭渡许禾，20岁》。值得记下的回帖：水府庙老陈说别在河边喊大名，提到“一五年冬至那回”；钓鱼佬阿强在下游K9听到有人应了一声，是女的；救援队夏雨说无人机照片传到了队里网站。把寻人启事图片点开放大，看最底下两行小字。

03救援队登记号

查到救援队的搜救记录。

方向

启事小字写了登记号的编法，日期要换成农历。

位置

小字是“BLD-失联当日农历月日-姓名拼音”，失联是8月25日，求助对象是许禾。农历在水府庙网站右边的黄历里查（吧里精品帖《今年水府庙中元放灯改成网上登记了》有链接，吧右侧友情链接也有）。救援队网站在吧右侧友情链接里。

答案

2026年8月25日是农历七月十三。救援队网站 → 求助登记查询 → 输入 BLD-0713-XUHE（大小写都行）。只输 BLD-0713 会提示还要加姓名拼音。

04航拍照片

找到出事的河段。

方向

搜救记录写了应声的位置，你手机里有一张照片拍到了那里。

位置

记录里 23:10 那一行：“晒谷场正对的河心”。相册里禾禾发来的晒谷场照片，河边立着一块里程石。

答案

里程石上写着“宁川河 K7”。在“航拍照片”里输入 K7，能看到芦苇边一盏写着“禾”的纸灯，逆着水流停在原地。下面还有一张 06:40 队员划船近拍的灯签：灯号 2026-0713-07，灯签号 SFM2026071307，最后四位被水泡糊了。最后烧撤灯条要用。

二、去年的平平

05去年的溺亡

弄清楚这段河以前出过什么事。

方向

搜救记录最后的备注提到了一篇报道。

位置

宁川融媒（吧右侧友情链接），右上角搜索。

答案

搜 溺亡、平平 或 许平，打开2025年9月7日《白鹭渡渡口一少年中元夜溺亡》：15岁的许某9月6日夜里落水，那天是他生日，也是农历七月十五；生日灯上写的是他的小名；事发时他的堂姐也在渡口。报道里还有一张他鹅聊空间的截图：昵称“平平别叫我平平”，鹅聊号打了码，只露出前四位 2815，下面是同学当天早上的生日留言。这篇是去年的旧闻，首页和右边的热点排行里都没有，只能搜。

06平平的鹅聊号

找到平平的鹅聊空间。

方向

号码分两半找：前四位在去年那篇报道里，后四位平平的爸爸在吧里说过。

位置

报道里那张鹅聊空间截图；吧里“渡口老许”的个人主页（寻人帖就是他发的）。他去年的帖子《儿子十五岁生日，放了盏灯》和《两个礼拜了》对得上新闻里那个孩子，签名就在他名字下面。

答案

截图里的鹅聊号打了码，只露出前四位 2815。老许的签名写着“尾号是他生日”，平平生日是9月6日，所以号码是 28150906。帖子《两个礼拜了》下面有鹅聊空间的链接，进去输入这个号。

07空间的问题

打开平平的空间。

方向

问题是“我最讨厌别人叫我什么”。

位置

报道截图里的昵称“平平别叫我平平”；手机朋友圈里大舅2025年8月30日那条。

答案

输入 平平。日志《生日》写了生日灯和堂姐在台阶上整理族谱。说说里 2025年6月20日那条要记下：平平跟妈约好，晚上回来晚了不敲门，在窗户底下吹两声口哨，妈下来开门，灯都不开。水底下第五级要用。留言板里有“秋云”（平平的妈妈，就是舅妈李秋云）七月初一凌晨留的“妈给你点了灯，窗户开着”；最后三条署名“（无名）”，是倒着写的，倒过来读：“水里好冷。我想回家。”“快了。”“姐应了一声。”

三、水底下

08冬至那回

弄清楚老辈人是怎么把人喊回来的。

方向

老陈在寻人帖里提到“一五年冬至那回”。冬至这个词会搜出很多无关的帖子。

位置

吧内搜索框旁边可以选年份。

答案

搜 冬至，年份选 2015，打开《【旧事】冬至那伢子是怎么喊回来的》。做法：等到子时，太婆在前头喊伢子的小名，屋里人在后头跟一声，喊到第三声人回来了。回帖里阿四说“零三年下游芦苇里卡着的那盏灯，你们都忘了？”，小编说老帖子在【历史存档】里按年份找。水府的门要问这盏灯。

09历史存档

读2003年那盏灯的事。

方向

存档是从老论坛迁过来的，按老办法纪年。

位置

吧首页的“历史存档”标签。

答案

2003年是癸未年，输入 癸未，打开《放灯以后》。那年七月半，王家的往灯上写了李桂兰的名字，李桂兰当晚在渡口应了一声就下去了；那盏灯卡在下游芦苇里不走，名字还在上面（同年另一帖《下游芦苇里卡着一盏灯》）。进水府的门要用李桂兰这个名字。老陈的回帖是后面要用的规矩：“写名字的是看灯人……灯撤了，契就落到看灯人身上。”阿四的回帖说被水叫走的人是“去水府应名了”：水府跟岸上一个样，庙里贴张榜，水府也贴一张，字是倒的。

10小名的规矩

弄懂外婆第三条语音的意思。

方向

外婆说的是“喊屋里叫个那个”。查一查白鹭渡的小名有什么讲究。

位置

水府庙网站 → 民俗 → 搜索。

答案

搜 小名，打开《白鹭渡取名旧俗》：小名多取旱地上长的东西，麦、粟、豆、薯；小名不落笔；喊魂喊小名，一个人在前头喊，屋里人在后头跟；七月里在河边有人叫你大名，莫应。顺手看《渡口的七级台阶》和《喊魂（未完）》，最后一步都用得上。

11进水底下

找到倒过来的网站。

方向

外婆的第二条语音：“水底下看人都是反个。”2003年那帖里也说，庙里贴张榜，水府也贴一张，字是倒的。网址可以自己改。

位置

水府庙“放灯公示”页，表格最底下有一行倒着写的字，下面还有一行倒着的拼音。拿它和这一页的网址对一对。

答案

那行字倒过来是“水里也贴了一张。”下面的 ihsgnog 就是这一页网址结尾 gongshi 倒过来。把网址里的 gongshi 换成它，打开 miao.html#/fangdeng/ihsgnog。

12第一级：门

进门。

方向

水底下的字都是倒的，回答也要倒着写。门上问：上一回，也有一盏灯卡在芦苇里，水推不走，灯上写的是谁。K7 那盏现在就是这样卡着的，吧里有人提过上一回。

位置

冬至帖里阿四的回帖（第8步）；历史存档 2003 年的两帖（第9步）。

答案

输入 兰桂李（李桂兰倒过来）。零三年王家的往灯上写了李桂兰的名字，那盏灯卡在下游芦苇里。正着写会提示是反的；写王家的会说“那是看灯人”；写许禾会说“她那盏还卡着”。门开了以后点“级一走下往”往下走。一次只看得见一级，每一级答对了才出现“级一走下往”。第二级起可以点“级一上回”回到上一级，点“上岸回”回庙里。从岸上再进来，要从门开始一级级往下走，答过的不用再答。

13第二级：名册

在水里的名册上找到许禾。

方向

你是来找许禾的。名字也要倒着写。

答案

在“？谁找你”里输入 禾许。正着写“许禾”会提示是反的，写平平会说“他在更下面”。名册上 2025 年是“平平　已渡　想回岸”，2026 年是“许禾　渡上”，看灯人的名字是三个星号。答对以后水里说：许禾，渡上，还没渡过去；渡上的人，要报生辰来认。

14许禾的生辰

查到许禾的生辰，在放灯公示里认出她那盏灯。

方向

公示表里灯主只露一个姓，生辰写全了。族谱里有她的生辰。

位置

水府庙“关于”页有《白鹭渡许氏宗谱》的链接，宗谱里搜 许禾。

答案

许禾生于丙戌年六月初九辰时，乳名一栏“依俗不录”。公示里灯号 2026-0713-07：灯主许*，生辰丙戌年六月初九，代放人写的是“庙里代登”，登记日期2026-08-22。庙里的灯只给过世的人放，这盏写的是活人。同一晚还有一盏 0713-03，灯主是平平，代放人李**。

15第三级：渡上

认准是她，确认她还喊得回来。

方向

渡上的人要报生辰来认，倒着报。

答案

输入 九初月六年戌丙（带上时辰写成“时辰九初月六年戌丙”也行）。回答是：她站在第七级台阶下面，已经应了两声，子时三刻以前还喊得回来；河心有人在叫她。

16第四级、第五级：回声和平平

弄清是谁在叫她，为什么。

方向

两个键，正着听不清的，倒过来。叫她“姐”的人，名册上有。第五级平平问他跟妈的记号，他自己在空间里写过。

答案

点 ◀，转写出来是一个男孩说：“姐，你再应我一声，我就回得来了。”接着问“叫她‘姐’的是谁”，输入 平平（输入许平会提示“水里叫他平平。灯上写的就是这个名字。”）。第五级平平说他想回家，水里待久了好些事记不清，问他晚上回去晚了跟妈的记号是什么。答案在他空间的说说里（第7步）：在窗户底下吹两声口哨。输入 哨口（口哨倒过来）。写敲门会说“敲门要吵醒爸的”，写开灯会说“妈不开灯的”。答对以后平平说：妈听到就下来开门，灯都不开；我的小名写在灯上，屋里喊不回我了；岸上有人又给我点了一盏灯，拿姐换我；灯撤过一回，又点上了；契跟着现在亮着的这盏，七月初十凌晨立的；还差一声，姐已经应了两声。点按钮“级一走下往”（往下走一级）。

四、谁写的灯

17许禾的小红书（现实）

拿到许禾的 GitHub 用户名。

方向

许禾在网上不止一个地方。宗谱是她做的，页脚写了联系方式。

位置

宗谱网站最底下“技术支持”那一行。

答案

在小红书搜 6529081560，昵称“禾不是河”。简介里“倒着找我：60ehux”倒过来是 xuhe06，“章鱼猫”指 GitHub。打开 github.com/xuhe06，能看到她的仓库 bailudu-zupu。

没有小红书：开源社页面上的项目展海报印着她的仓库地址，被招新贴纸挡了一半，能认出 bailudu-zupu，在 GitHub 搜 bailudu 也能找到。

GitHub 打不开：开源社页面最下面“代码在哪”有社里的镜像“码仓”，搜 xuhe06 或 bailudu 就能进她的仓库，内容跟 GitHub 上一样。

18禾的小站

找到许禾的博客。

方向

禾禾8月1日给你发过一篇文章。

位置

微聊“禾禾”里8月1日的链接卡片《把族谱搬上网》。

答案

文章里有三件事：放灯登记表单会用庙里的账号自动提交到仓库，提交时间就是登记时间；后台账号在陈伯住院那几天交给大伯代管；代码在 GitHub，海报上有链接。文章底部的“开源社”链接通往开源社页面。

19GitHub 上的仓库

查到那盏灯是什么时候、用什么账号登的。

方向

博客说过，提交时间就是登记时间。仓库不用登录就能看，首页 README 写了怎么查。

位置

github.com/xuhe06/bailudu-zupu → 打开 lanterns/2026.csv → 右上角 History（提交记录）。每条加灯提交的标题里写着登记时间（北京时间），比如“加灯：2026-0713-07（2026-08-22 03:05 登记）”。列表的日期分组按格林尼治时间分，可能比标题里的日期早一天，以标题为准。GitHub 打不开就用码仓：仓库页点“提交”，提交记录一样，时间直接按北京时间显示。

答案

关键的三条（北京时间）：

  • 08-13 02:17，bailudu-temple，加灯 2026-0713-07，来源：后台（第一盏，后来被撤了）
  • 08-20 21:46，xuhe06，撤掉这盏灯，说明“灯主还活着”
  • 08-22 03:05，bailudu-temple，又加回去，来源：后台（现在亮着的就是这盏）

点开任一条加灯提交，能看到新增的那一行写着灯主“许禾”。README 里还写着：管事不在时后台交给理事代管，用后台登的灯才会写“来源：后台”。平平说契跟着现在亮着的那盏、七月初十凌晨立的，就是 8月22日 03:05 这条。第23步问陈伯、最后烧条子的灯签号，都用它。

20第六级：灯契

读到灯契，弄清这张契是怎么立起来的。

方向

平平那一级答完，点“级一走下往”。这一级不用答题，到了就能读。

答案

契文是：“七月初十寅时，以许禾之名，替平平回岸。看灯人：＊＊＊。灯不灭，契不解。”下面是水里讲的这张契的来历：头一回灯还没下水，许禾自己把灯撤了，留了一句“灯主还活着”；隔了两天灯又点上了。七月十三夜里八点放灯，写许平的那盏顺水走了，写许禾的那盏停在晒谷场对面的芦苇边上（就是 K7 那盏）。九点多她在渡口应了一声，手机掉在第七级台阶上；十一点岸上的人沿河喊她大名，河心又应了一声。契纸底下留着三个押，应一声按一个，已经按了两个。所以最后绝不能让她再应水一声。

看灯人的名字水里不念，要等最后在岸上烧了条子才显出来。到了这一级就算读过灯契，家族群里小姨会说外婆夜里十一点去渡口，打视频给你。视频要等你加上陈伯以后才打进来。

21第七级：台阶底下

走到最底下一级，听清最后的规矩。

方向

灯契读完，点“级一走下往”。这一级不用答题，每句话都有用。

答案

第七级写着：她就在下面；水太凉，她只认得屋里叫她的那个名字；子时让屋里人在岸上喊，喊大名她就应了水。灯放下水了，岸上撤不脱，要在渡口烧条子，条子上写清是哪一盏、看灯人是哪个；写准了，契落到他身上，写错了，契落空，当夜落回她身上。

最后台阶底下传上来禾禾的声音，她只够时间留下一句话（加粗的那句）：“溪，我给你留了话，锁在我的小站上。钥匙是我们第一次一起放灯那年，照奶奶那样讲。”这是下一步加密文章的钥匙。第七级是最底下一级，没有“级一走下往”了。

22加密文章

读许禾留给你的信。

方向

钥匙在第七级许禾那句话里：我们第一次一起放灯那年，照奶奶那样讲。相册里有那年的照片，奶奶那辈人用干支纪年。

位置

禾的小站首页那篇加密的《如果我没回来》；手机相册第一张，2014年8月10日。

答案

2014年是甲午年。密码框只收字母和数字，输中文会提示“密码只能是字母或数字”，输 2014 会提示“奶奶不这么说年份”，所以用拼音 jiawu。

信里交代了最后要做的事：这盏灯七月十三晚上就放下水了，网上撤不了；怎么撤奶奶晓得，要去找奶奶。光撤灯不够，还要找陈伯锁号，他的微聊号是 shuifu-chen，加他要报家门。小名就在那条语音里，别写下来，打字也不行。

五、子时

23找陈伯锁号

让大舅没法再把灯登回去。

方向

陈伯的微聊号在许禾的信里，他认人不认号。他这些天在家养病，放灯的事没经手，你得告诉他这盏灯是什么时候登的。

位置

许禾的信；手机 → 通讯录 → 添加朋友。登记时间在 GitHub 的提交记录里（第19步）。水府庙首页8月11日和8月17日的公告写了陈伯那些天在哪。

答案

搜 shuifu-chen。验证消息要报家门，写上你妈妈的名字，比如“陈伯，我是秀英家的程溪”。写外公许德昌、外婆周桂香也行，他们是这一家最大的一辈，名字在宗谱里都查得到。陈伯一通过，外婆的视频就打进来了（要先读过水底下的灯契）。可以点“接听”先接外婆，也可以点“先跟陈伯说”。想要真结局，先跟陈伯说完：

  1. 选“陈伯，庙里放灯的后台，有人拿去给禾禾登了一盏灯”。陈伯说他没过手，问是什么时候登的。
  2. 选“七月初一凌晨两点十七，七月初十凌晨三点零五，两次都是‘庙里代登’”。另外两句是放灯的时间（七月十三晚上八点）和许禾撤灯的时间（八月二十号晚上九点四十六），陈伯会说不对。

陈伯想起那几天后台的号交给了建国，当场改号，关掉网上放灯。他还会说灯放下水了网上撤不了，只能在渡口烧条子，叫你快去回外婆的视频。回到手机首页，外婆会再打来；也可以点首页的通知回拨。

24子时的视频

跟外婆一起烧掉撤灯条，再把许禾喊回来。

方向

外婆先烧条子，问两样：灯签号，和看灯人是哪个。灯签号必须报对才往下走，它在灯签上，后四位泡糊了。看灯人就是在灯上写禾禾名字的人，想让平平回来的不止一个：大舅、舅妈、理事王有福。舅妈在陈伯住院那几天守着庙里帮老人家登灯，两次登灯的半夜她都醒着，去年还怨过带平平去渡口的人；王有福是理事，他娘二〇〇三年干过这种事。光猜动机定不了人，要看这盏灯是用什么登的，谁拿着庙里的后台。烧完条子再喊人，每个问题前面都见过答案，外婆在前头喊，你在后头跟。

位置

灯签：救援队 K7 航拍下面那张近拍；须知里写着灯签号最后四位是登记时分（北京时间）。看灯人：水府庙首页8月11日的公告（后台交给一位理事代管）；禾的小站《把族谱搬上网》（交给了谁）；公示里这盏灯是“庙里代登”；吧里“渡口老许”的《睡不着》；GitHub 上两条加灯提交的时间。视频从外婆打来的邀请接，错过了就点手机首页的通知或桌面上的“电话”。

答案（按顺序）
  1. 在，外婆
  2. 到了，现在十一点（子时是23点到1点，庙里黄历有十二时辰表）
  3. 灯签号输入 SFM20260713070305，点“讲给小姨”。灯签上看得清的是 SFM2026071307，泡糊的四位补上8月22日那次的登记时分 0305。这一步只报一遍，报错了当场就说：只报灯签上那一串，小姨会问后头四个数；报 02:17 那盏的号，外婆说那是撤掉的那盏；后四位不对，外婆说水里冇这盏灯。报对了小姨写上，接着问看灯人。
  4. 外婆问看灯人是哪个：选“写名字”，输入 许建国（写“建国”也行），点“讲给小姨”。陈伯住院时后台交给了大伯（博客里写明了），0713-07 是用后台登的；两次登灯都在半夜，08-13 02:17 登完，02:31 他在吧里发帖说睡不着；08-22 03:05 又登上，03:20 他在同一帖下面回“又梦见了”。舅妈可以排除：她登的 0713-03、0714-09、0715-04 代放人都写“李**”，GitHub 上都是“来源：网站表单”，她碰不到后台。王有福家的事，存档里写着二〇〇四年就了结了。只写“大舅”“大伯”这样的称呼，小姨会说要写大名。千万别报小名。写错了人，条子照样烧，K7 的灯也会灭，但契落空，进坏结局「落空」。选“我不晓得”就不烧条子。
  5. 条子烧完，外婆问她站在第几级：输入 7
  6. 外婆要你讲她屋里叫的那个名字：有“开口念”和“打字发过去”两个选项，点“开口念”。外婆不识字，小名也不能写；打字也是在拼音板上拼，可把小名打出去就算写下来了，直接进坏结局。拼音板上的“返回”可以换另一个选项。
  7. 拼第一个音 a1：声母选 ∅，韵母选 a，声调选第一个（高而平），点“加上这个音”。拼第二个音 mo5：声母 m，韵母 o，声调选第四个（从高往下掉），点“加上这个音”。然后点“念给外婆听”。依据是禾禾那条语音的转文字“ā mò，ā mò，转来哦”：ā 是高平调，mò 是往下掉的调，在拼音板上选出来就是 a1 和 mo5。拼错五次就过了子时三刻。
  8. 外婆问是哪个 mo：选“地里长的”，是麦。小名取旱地上的东西。
  9. 外婆喊完，我跟一声
  10. 跟一声（1/3），跟一声（2/3）
  11. 河里有人喊“许禾——”，选“跟着外婆喊她小名”
  12. 跟一声（3/3）

结局

结局的条件

结局有四个，普通结局分两种。结局单独一页，不在手机里显示。

  • 真结局「看灯人」：视频里撤灯条烧对了（灯签号对，写的是许建国），之前也找陈伯锁了号，再跟着外婆把三声喊完。许禾回来了；第二天大舅没回来，第七级台阶上只有他的鞋。之后回到禾禾的对话框，再看一次第一天那条语音的转文字。
  • 普通结局「灯还在」：人喊回来了，但条子没烧，K7 那盏灯还在；或者条子烧对了，号没锁，大舅当晚又补登了一盏。结局页最后一句会提示差的是哪一步。
  • 坏结局「落空」：撤灯条上写错了看灯人。K7 的灯照样灭，可喊到第二声，她先应了水。写的是谁，结局里有一句不一样。
  • 坏结局「应声」：河里喊“许禾”时你也喊“许禾”；屏住不出声；让小姨把小名写上了条子；之前在聊天框打过小名；视频里把小名打成了字；拼错五次。

结局页有“回到和外婆的视频，再选一次”：调查进度都留着（锁号、读过的灯契都在），只把那一夜重来，条子要重新烧。回到手机以后也能回去：手机桌面上外婆那条通知（真结局没有这条），或者点“电话”，都能回到那通视频。普通结局没锁号时，结局页还有“去找陈伯”，锁完号外婆会再打过来。想从头玩，点结局页或桌面上的“重新开始”。条子烧对以后再去水底下，名册和灯契上会显出看灯人的名字。
